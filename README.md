Для внедрения бота в ваш Discord сервер, вам нужно:
1.Сделайте самого бота данное видео поможет вам https://www.youtube.com/watch?v=uXl_Pi2tB2o&t=265s
2.Вам нужно сделать Api ключ для запросов, для этого вам нужно сделать аккаунт в Yandex cloud и в разделе Yandex Ai studio создать Api-ключ
3.Вам нужна будет среда разработки поддерживающий язык Python,а тажке для работы скрипта нужно написать в консоль эту команду: pip install discord.py openai python-dotenv
4.Скачать текстовый файл, где вам нужно скопировать текст и вставить в вашу среду разработки
